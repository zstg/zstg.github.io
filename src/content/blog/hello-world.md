This is my first blog post. I'm setting up this site using Astro, SolidJS, and Tailwind CSS.

## Why this stack?

- **Astro** gives me a fast static site with minimal JavaScript shipped to the client.
- **SolidJS** lets me add interactive islands where I need them — animations, parallax, dynamic UI.
- **Tailwind CSS** makes styling fast and consistent.
